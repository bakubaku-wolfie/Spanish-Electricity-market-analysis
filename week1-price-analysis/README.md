# Week 1 - Price Analysis Pipeline

Spanish electricity market price analysis built with Python, pandas, matplotlib and scikit-learn.

## What this project does
- Data loading and cleaning
- Statistical analysis of price and load
- Intraday price pattern visualization
- Correlation analysis between price drivers
- Linear regression forecasting model with train/test split
- MAE: 9.48 EUR/MWh

## Dataset
Hourly Spanish electricity market data 2015-2018 (35,000+ observations)
