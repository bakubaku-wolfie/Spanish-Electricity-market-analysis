# Week 2 - Market Dashboard

Spanish electricity market analysis dashboard built with Python, pandas, matplotlib and seaborn.

## What this project does
- Intraday and seasonal price pattern analysis
- Correlation heatmap across generation sources
- Price spike analysis by month and hour
- Price duration curve
- Solar vs wind seasonal complementarity

## Dataset
Hourly Spanish electricity market data 2015-2018 (35,000+ observations)
